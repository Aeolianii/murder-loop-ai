# 《23:47》剧情设计文档

> 版本: v3.1 | 最后更新: 2026-07-22
> 
> **v3.0 变更**: 结局系统从三结局改为五档多维评分；死亡不再是结局，是循环机制；新增知识激活系统、多线可变凶手、叙事式断案、灵光一现引导、跨循环持久化。

> **注意**: 评分权重、断案阈值（知识≥3条）、灵光触发次数（2/4/6次）均为初始设计值，需要在实现后通过玩测调整。

## 一、故事背景

### 地点

**青荷公寓**，六层老式居民楼。一楼物业办公室，二楼到六楼出租房。没有电梯。503 朝北，窗外是隔壁楼的墙。表面上是一个普通出租公寓，实际是洗钱网络的转运节点——五楼被用来短期藏匿现金、毒品和账本，租客流转快，没人注意。

### 前史

**李汶涛**，30 岁，会计。两年前给赵鸿远的皮包公司做账，被卷进了洗钱操作。他怕了，想退。赵鸿远说行——条件是他在 503 住三个月，负责收转几批货。

李汶涛在 503 期间做了三件事：

1. 偷偷复制了近两年的洗钱账本（U盘），记录了每一笔通过青荷公寓的转账和参与者的代号
2. 观察了陈怀民的行动规律——巡视时间、交接方式、备用钥匙位置——记在笔记本上，藏在 403 地砖下
3. 给了维修工林越一个模糊的警告："如果我一周后还没联系你，包裹在 503"

他知道自己的电话和行踪被监控，于是通过最土的方式寄出包裹——便利店买胶带和一次性手机，真空包装 U盘和现金，面单写"青荷公寓 503"。他赌的是陈怀民收到后会以为是内部转运货。他赌错了——陈怀民打开了包裹，看到了 U盘，慌了，没有告诉赵鸿远，而是扣下来自己查。**同一天，李汶涛被赵鸿远的人处理了。**

## 二、人物

### 信息不对称矩阵

```
Layer 4 (全知) ─ 赵鸿远: 一切。组织全貌、公安内线、李文涛已死。
Layer 3 ────── 陈怀民: 包裹内容（毒品+钱+U盘）、李文涛死了、有假警察资源。
                    不知道: U盘密码在哪、玩家有没有备份、赵鸿远会随时弃他。
Layer 2 ────── 林越: 李文涛走前留了话、403有奇怪东西、陈怀民最近很紧张。
                    不知道: 包裹具体内容、陈怀民是执行者、有假警察、赵鸿远存在。
Layer 1 (初始) ─ 玩家: 23:00 回家，桌上有包裹。
                    不知道: 一切。每死一次往上突破一层。
Layer 0 (死者) ─ 李汶涛: 已死。留下: 包裹、U盘、笔记本、定时报警、对林越的话。
```

### 沈知夏（玩家）

26 岁，软件公司新人，三天前签了 503 的租约。搬家那天是 7 月 17 日——潮湿、闷热、傍晚开始下雨。她是"恰好卷入"的局外人。循环给了她独特的优势——她是唯一能跨轮次积累信息的人。

### 陈怀民

青荷公寓物业经理，53 岁。年轻时做过保安、辅警、收债人。赵鸿远每月多给他一万，条件是"不问、不看、不管"。他是整个组织里最底层但也最关键的一环——物流中转就在他的楼里。

他不是"坏人"——至少他自己这么认为。他只是干活的人。但李汶涛的事让他破了规矩——他打开了包裹。现在他必须在**赵鸿远知道之前**把 U盘拿回来。所以他在 47 分钟里的所有行动都是矛盾的——既要拿，又不能闹大。他是信息不对称最大的受害者和施害者。

### 林越

青荷公寓维修工，27 岁。陈怀民的同事。他在楼里干了两年，什么人都见过。李汶涛是这栋楼里唯一愿意跟他多说两句的人——两个人在楼梯间抽过几次烟，聊过楼里"那些奇怪的快递"。

李汶涛失踪后，林越留心上了。他以维修工的身份查了一些东西：403 空着但桌上有烟盒、503 门锁周围有新划痕、陈怀民最近上班会多看一眼五楼走廊。他没有结论——他只是觉得不对劲。但正是他的碎片 + 玩家的碎片，才能拼成完整的图。

他的信息盲区：他不知道包裹里是 U盘和账本，不知道陈怀民就是执行者，不知道有假警察，不知道赵鸿远。他只是个"不对劲"的记录者和追问者。

#### 林越信任线：三阶段递进

信任不是一次性事件。玩家和林越的关系需要逐步建立：

**阶段 1 · 试探（循环 2-4）**
- 林越在走廊提到"之前住 403 的那个人"，但声音压得很低——陈怀民随时可能经过
- 如果玩家追问太急、太大声 → 陈怀民听到 → 支走林越："小林，五楼水表查过了没？" → 本轮失去林越的联系
- 如果玩家压低声音回应 → 林越会约"回头再说"，下一轮主动给你发消息

**阶段 2 · 证据交换（循环 4-8）**
- 你给林越看包裹照片 → 他认出 403 的收据日期——"这个日期……李汶涛失踪那天。"
- 他给你看 403 的发现——烟盒、催缴单、抽屉里的纸条
- 一人出一半，拼图才完整。交换后激活知识 "林越在追查李汶涛失踪"

**阶段 3 · 牺牲抉择（23:40 之后）**
- 林越面临选择：上楼帮你（可能死），还是留在楼下报警（安全但来不及）
- 他的选择取决于之前你给了他多少信任：
  - 如果只到阶段 1 → 他留在楼下，但报警来不及
  - 如果到了阶段 2 → 他上楼，但会先备份你给他的证据再上来
  - 如果阶段 2 + 你明确警告过他有假警察 → 他留在安全位置协助报警和备份证据，成为外部协作者

### 李汶涛（死者）

从不在台前出现。但他留下的痕迹是玩家的通关钥匙：

- **包裹**（证据集合）——胶带手工缠了三层、面单只剩"青荷公寓 5-0"、连号新钞（银行封条日期三天前）、U盘（磨损，标签"0724"）
- **403 收据**——便利店购买的胶带+记号笔+一次性手机，日期一周前。背面手写"青藤公寓 403"
- **403 遗物**——半包烟（和雨棚上同品牌）、纸条"如果他来，就说我搬走了"、地砖下的笔记本（U盘密码 + 监控日志）
- **定时报警**——23:23 自动接警："青荷公寓 503 有可疑物品"。他知道如果自己死了，至少有人来查。**如果玩家在 23:23 之前已经联系了真警察**，接线员会说"等一下，系统里有一条预置记录……"——李汶涛的报警和玩家的报警在系统里连上了，这会触发警察对青荷公寓的重新评估
- **笔记本的空白页**——李汶涛故意留了几页空白。对着光看（inspect 纸张），空白处有针孔字迹——用针戳出来的盲文式暗号："赵，公安，内。"这不是写给后来人的——是他自己的备忘录，记在只有自己知道的地方
- **最后一个电话**——手机通话记录里，23:00 有一条已拨电话，通话时间 0 秒——对方没接。号码是林越的。他死前最后想联系的人是林越。如果玩家把这个信息告诉林越，林越的反应会完全不同——"他最后找的是我？"——信任线直接跳到阶段 2
- **对林越的话**——"东西在 503"

### 赵鸿远

青荷公寓产权代理人，实为洗钱网络的控制者。40 多岁，从不亲自出现在楼里——所有命令通过电话、微信、或陈怀民转达。他对陈怀民的态度是"用着顺手但说扔就扔"。

他的最大弱点：**信息延迟。** 他不在现场——所有情报都靠别人转述。陈怀民没说实话的时候，他什么都不知道。玩家比他早 20 分钟知道真相。最终玩家赢的方式，就是利用这个信息延迟，让他一步步犯错。

#### 赵鸿远的痕迹——他来过，只是你没看到

赵鸿远不在台前，但他的存在感必须渗透在细节里：

- **陈怀民的手机**：如果玩家设法拿到陈怀民的手机（策反后他给的、或者他死后捡到的），微信里赵鸿远的消息风格和陈怀民完全不同。赵鸿远从来不打字——只发语音。每条 5-10 秒。语气平静，像在安排物流。"503 那个女的，查一下她搬进来之前住哪。"最后一条——发在李文涛死的那天——"503 那个，处理掉。别留东西。"
- **403 监控日志里的"赵先生"**：李汶涛的笔记本里详细记录了陈怀民每天的巡视时间，但在几页边角用铅笔写着："赵，22:15，黑色凯美瑞，不下车"、"赵，23:40，车里抽烟，等陈出来才走"。赵鸿远来过很多次——但从不下车。他像一个幽灵，车轮碾过青荷公寓门口的积水，没人听到。
- **林越也见过他**：如果玩家在信任线阶段 2 问林越"这栋楼有没有你认不全的人"——林越会想起来："有一次我在楼梯间修灯，听到楼下有人喊'赵哥'。陈怀民喊的。那个人没应声——车门一关就走了。"

## 三.五、真假警察分辨训练

玩家需要学会分辨真假警察。这不是一次性的知识获取——需要多次接触才能掌握。

### 信息来源

| 来源 | 触发条件 | 获得什么 |
|------|---------|---------|
| 林越（信任线阶段 1） | 玩家问"怎么知道外面的人是不是真警察" | "我也不太确定——我只见过一次，那人先报了警号才问话的。"林越自己分不太清，但他给了方向 |
| 陈怀民（策反后） | 玩家策反陈怀民 | "假警察是组织的人。他们不用警号——用内部编号。你听他们说话就知道了，真警察先报身份，假警察先问情况。" |
| 实战观察 | 23:20 假警察到场 + 23:33 真警察到场 | 同一轮遇到两组警察，对比他们的问话方式 |

### 辨识特征

| 维度 | 真警察 | 假警察 |
|------|--------|--------|
| 开场方式 | 先报警号、所属派出所、接警编号 | 先问"503 有人报警？"、"你一个人住？" |
| 证件出示 | 主动出示、可以通过门缝看到证件照片 | 口头自称、证件在手里晃一下不让你细看 |
| 警车 | 有警车声（不一定开警笛但能听到引擎声和车门关闭声） | 没有——普通车辆、或者停在远处走过来 |
| 对陈怀民的态度 | 询问、核实——"你是物业？这栋楼最近出过事吗？" | 陈怀民提前知道他要来、两人低声交流 |
| 调度确认 | 可以回拨 110 确认出警记录和调度编号 | 回拨 110 查不到——"今晚没有警员派到青荷公寓" |

### 双警察同场的场景

23:36 左右，真警察和假警察同时出现在楼下。玩家看不到窗外，只能听到声音：

- 听到一个警察报了警号——另一个没报
- 听到引擎声和车门声——但先到的那组警察是走过来的
- 听到陈怀民和其中一组低声说话——另一组在问"你谁啊？"

玩家需要根据之前积累的辨识知识判断：哪组是真的？这决定了玩家接下来的行动方向——开门配合、继续拖延、还是从窗户逃生。

如果玩家在之前已经通过林越或陈怀民学会了分辨方法，这个场景的"听力题"会更容易——系统在叙事中会加入更多可辨识的细节。如果玩家什么都没调查就遇到了双警察场景，叙事会比较模糊，玩家只能凭直觉赌。

如果玩家什么都不做，这 47 分钟：

```
       陈怀民沉默。开始调监控。

       林越看见纸箱，回去报告。

23:40  陈怀民决定自己来——拿了备用钥匙，上五楼
23:43  林越意识到事态不对，开始上楼
23:45  陈怀民进不去——门锁了有链子。用肩膀撞门。
23:47  玩家死亡。
```

每个事件都带 `condition?: (world: WorldState) => boolean`——玩家的行动可能使某些事件不发生或不按此方式发生。

## 五、五幕结构

### 第一幕 · 恐慌（循环 1-3）
**信息层**: Layer 1，什么都不知道
**核心问题**: 谁要杀我？为什么？

玩家尝试不开门、报警、交出包裹——全失败了。唯一收获：死在 23:47 是定数。发现包裹里有 U盘 + 现金——不是普通快递。

### 第二幕 · 敌友难辨（循环 3-6）
**信息层**: 进入 Layer 2，发现林越
**核心问题**: 林越可信吗？警察是真的吗？

发现林越是李汶涛唯一信任的人、陈怀民有备用钥匙、真假警察分辨方式（问的问题不同）。突破：知道林越可以信任，知道怎么识别假警察。

### 第三幕 · 李汶涛的遗产（循环 5-10）
**信息层**: 进入 Layer 3
**核心问题**: 包裹到底是谁寄的？U盘密码在哪？

调查 403 → 找到烟盒和纸条 → 林越说出李汶涛的遗言 → 拿到密码 → 打开 U盘：账本 + 成员代号 + 监控日志。"1103"——陈怀民的上线编号。

### 第四幕 · 猎人与猎物互换（循环 10-18）
**信息层**: 进入 Layer 4
**核心问题**: 1103 是谁？怎么让他露出破绽？

玩家掌握主动性——提前布置藏包裹、假报警、设局。赵鸿远注意到异常——改策略：狙击而不是进门，提前行动。玩家意识到敌人也在适应。

### 第五幕 · 收网（循环 15-25）
**信息层**: 全 4 层信息打通
**核心问题**: 怎么把证据传到外面，同时让赵鸿远露面？

- 包裹藏 502 → 陈怀民找错地方
- U盘发给林越 → 外部分发
- 假警察被误导去衣柜 → 真警察拿证据
- 陈怀民知被弃 → 倒戈
- 赵鸿远被迫出面 → 被录下

**结局条件**: 证据链完整 + 赵鸿远身份暴露 + 警察可信 + 林越活着

## 六、游戏设计原则

### 信息密度原则
每一句话都是线索或伏笔。没有纯氛围描写。LLM 被告知：不写"窗外雨声淅沥"，写"雨棚上有半截烟蒂还没被雨水冲走"。

### Chekhov's Gun 升级版
第一幕的枪、弹壳、持枪姿势、火药残留、购买收据——每一项都在后续成为证据链的一环。同一个细节在不同幕有完全不同的含义：

| 事实 | 第一幕解读 | 第三幕解读 | 第五幕解读 |
|------|----------|----------|----------|
| 门锁划痕 | 旧锁磨损 | 陈怀民试过备用钥匙 | 23:08 试的，不是原装钥匙 |
| U盘标签"0724" | 编号 | 李汶涛的囚号或编号 | 赵鸿远生日？U盘密码？ |
| 林越在走廊 | 可疑的人 | 查李汶涛失踪 | 有 403 钥匙，可以进去取证 |
| 窗外烟蒂 | 前住户丢的 | 李汶涛监视过什么 | 他在监视陈怀民的交接 |
| 未接来电 4 秒 | 打错了 | 陈怀民确认你在家 | 来电时间 = 陈怀民行动时间表 |

### 后台运行原则
- **NPC 按阶段变化**: 不是硬编码事件，而是按时间窗口改变 goalStack + riskTolerance。具体怎么做由 LLM 决定。
- **事件涌现**: 两个 NPC 状态碰撞 → 相遇事件。不是预写"23:08 林越敲 503 的门"——而是陈怀民 goalStack 里有 `confirm_package_location`，林越 goalStack 里有 `observe_corridor`，两人在 corridor_5f 相遇 → 陈怀民让林越去敲门。
- **玩家行动驱动时间**: 每步 action 耗时 1-5 分钟，后台在此期间推进世界，NPC 自主决策。

### 剧本杀特色
- **每轮 = 一个推理回合**，死亡不是惩罚，是获得新信息
- **信息不对称** 是核心谜题——不是"凶手是谁"，而是"谁在骗谁、谁被谁利用、谁知道的比说出来的多"
- **线索依赖图**: 有些线索必须组合才能推出结论（403 收据 + 雨棚烟蒂 + 林越的遗言 → 李汶涛在监视陈怀民）

## 七、结局系统设计

### 核心设计哲学

**死亡不是结局。** 死亡只让时间回溯到 23:00，循环继续。真正的结局是玩家**主动选择断案并打破循环**。

**"凶手是谁"只是第一层问题。** 知道陈怀民动手 ≠ 破案。真正的推理是：谁让他动手的？为什么是今天？包裹里到底是什么？李汶涛为什么死？假警察从哪来的？

### 可变凶手：不同条件触发不同死亡路径

每一轮 23:47 动手的人，取决于该轮玩家的行为触发了哪条死亡路径：

| 死亡路径 | 触发条件 | 动手的人 | 玩家第一反应 | 真相 |
|---------|---------|---------|------------|------|
| 灭口 | 玩家拆了包裹、拍了照、报了警 → 陈怀民确认她知道太多 | 陈怀民 | "房东是杀人犯" — 对但太浅 | 他只是执行者，上面还有人 |
| 执法 | 陈怀民搞不定 → 通知组织 → 假警察出场 | 假警察 | "警察是假的" — 对但不够 | 假警察不是陈怀民找的，是赵鸿远的资源 |
| 嫁祸 | 玩家信任林越 → 陈怀民误导林越 → 林越上楼查看时被利用 | 陈怀民（现场证据指向林越） | "林越是帮凶？" — 错 | 林越被设计了 |
| 清理 | 赵鸿远发现事情闹大 → 越过陈怀民直接派人 | 赵鸿远的人 | "入室抢劫？" — 错 | 组织在收线 |

### 嫌疑人网络

每个人在不同信息层看起来都有嫌疑。排除一个嫌疑人 = 把他的信息和资源变成玩家的资产：

| 嫌疑人 | L1 印象 | 可疑行为 | 排除条件 | 排除后获得 |
|--------|--------|---------|---------|----------|
| 陈怀民 | 房东，有钥匙 | 监控你、撒谎 | 发现他只是执行者——他怕赵鸿远比怕警察多 | 可利用的恐惧（策反） |
| 林越 | 维修工，有整栋楼钥匙 | 在走廊徘徊、知道包裹 | 找到李汶涛遗言 + 林越报警记录 | 外部同盟（备份证据、报警） |
| 李汶涛 | 包裹寄件人 | 人消失了但东西还在 | 找到纸条 + 林越确认失踪 | 他的遗产（U盘密码、监控日志、定时报警） |
| "警察" | 自称警察来了 | 问话方式奇怪、不报警号 | 回拨 110 没有出警记录 | 识别真假警察的方法 |

### 红鲱鱼网络

| 红鲱鱼 | 前期线索（误导方向） | 排除证据 | 排除后得到的真线索 |
|--------|---------------------|---------|-------------------|
| "林越是帮凶" | 有 503 钥匙、在走廊徘徊 | 李汶涛遗言 + 林越报警记录 | 林越是唯一可信任的外部证人 |
| "包裹是毒贩的" | 真空包装、现金连号 | U盘账本、"1103"不是毒品编号 | 不是贩毒，是洗钱——性质完全不同 |
| "403 住户还活着" | 烟盒新、催缴单近 | "如果他来就说我搬走了" + 失踪确认 | 李汶涛预感到死亡 |
| "真警察有问题" | 警察和陈怀民说话、没立刻上来 | 回拨 110 确认接警记录 | 真警察被陈怀民拖延了，不是同伙 |

## 八、多维度评分体系

### 评分维度

| 维度 | 满分 | 含义 | 判据 |
|------|------|------|------|
| truthLayer | 100 | 揭示了哪层真相 | L1=25（知道陈怀民不是主谋）、L2=50（知道林越可信+假警察真相）、L3=75（知道李汶涛遗产+组织网络）、L4=100（知道赵鸿远+内鬼） |
| evidenceStrength | 100 | 证据能否在法律上成立 | 照片=20、U盘=40、U盘+密码=60、+外部备份=80、+证人+警方核验=100 |
| externalReach | 100 | 证据传出去了吗 | 只有玩家知道=0、林越拿到备份=40、警方拿到=70、公开/媒体=100 |
| survivors | 100 | 无辜者存活 | 林越死=0、林越活=60、+玩家无伤=100 |
| cycleCost | -100~0 | 循环次数惩罚 | ≤5轮=0、6-10=-20、11-15=-40、16-20=-60、>20=-100 |

### 加权公式

```
总分 = truthLayer×0.35 + evidenceStrength×0.30 + externalReach×0.25
     + survivors×0.15 + cycleCost×0.05
```

### 结局分层

| 档位 | 总分 | 叙事落点 |
|------|------|---------|
| S | ≥90 | 证据链完整公开，赵鸿远被逮捕，组织网络被摧毁，李汶涛之死得到交代 |
| A | 70-89 | 警方拿到关键证据开始调查，但赵鸿远提前脱身，组织伤到元气 |
| B | 50-69 | 陈怀民被逮捕，组织切割了他，真相只揭露了表层 |
| C | 30-49 | 玩家知道了一切但证据不够，只能匿名举报后逃离城市 |
| D | <30 | 活下来了（不再循环），但没人知道 503 发生了什么 |

## 九、断案系统

### 线索 → 知识

线索需要组合才能形成可用的知识。断案校验的不是"你收集了多少条线索"，而是"你激活了多少条知识"：

```
线索层（原始数据）                    知识层（可断案的命题）
─────────────────────                ─────────────────────
包裹面单残片"青荷 5-0"  ─┐
403 收据"青藤公寓 403"  ─┼─→ 知识: 包裹不是寄给我的，是寄错到 503 的
门锁新划痕              ─┘

未接来电 4 秒           ─┐
陈怀民敲门时间 23:12    ─┼─→ 知识: 陈怀民在用电话确认我在家
陈怀民有备用钥匙        ─┘

真假警察问的问题不同    ─┐
回拨 110 查不到出警记录  ─┼─→ 知识: 门外"警察"是假的，是组织调来的
陈怀民提前知道"警察"要来 ─┘

U盘+密码+403笔记本        ──→ 知识: 组织有公安内线，1103 = 赵鸿远
```

### 断案流程

```
玩家输入 "我要指认真凶" / "我知道怎么回事了"
  ↓
Parser 解析 intent: 'accuse' 或 'reveal_truth'
  ↓
系统检查：已激活知识 ≥ 3 条？
  ├── 否 → 叙事提示（角色内心感受），不建议直接告诉缺什么
  └── 是 → 进入断案
           ├── 玩家用自然语言陈述推理
           ├── 系统逐条校验：每个论断有没有线索支撑
           ├── 对的 → 确认并锁定
           ├── 错的 → 叙事化提示"不太对"
           └── 生成评分 → 进入终局
```

### 终局 + 回溯

断案后走完结局叙事。如果 truthLayer ≠ 100（S 档），结局播完后系统给出叙事化提示，玩家可选择回溯：

| 档位 | 回溯提示（叙事化，不指令，不剧透） |
|------|------|
| A (70-89) | 雨声还在。她闭眼，又睁开——有一件事她还没想通。 |
| B (50-69) | 陈怀民的脸她记住了。但她总觉得，那个电话号码后面还有别人。 |
| C (30-49) | 她活到了天亮。但 403 那扇门后面是什么，她不知道。 |
| D (<30) | 她睁开眼。雨声落在窗外。又是 23:00。 |

S 档不提示回溯——故事真正结束了。

## 十、知识激活系统

### 两层追踪

| 层 | 含义 | 示例 | 何时变化 |
|----|------|------|---------|
| 线索层 | 玩家发现了什么原始事实 | 包裹拆开了、U盘看到了、403 收据找到了 | 玩家执行对应动作时 |
| 知识层 | 线索组合后自动形成的可陈述命题 | "包裹不是寄给我的"、"门外警察是假的" | 线索满足组合条件时系统自动激活 |

线索需要玩家主动操作。知识由系统自动检测——不要求玩家显式说出推理过程。

### 知识定义

每条知识 = 名称 + 所需线索集合 + 互斥知识 + 激活效果：

```
知识: "包裹是寄错到 503 的"
  所需: [包裹面单残片, 403收据]
  互斥: "包裹本来就是寄给我的"
  激活: truthLayer += 10, 解锁调查方向"403"

知识: "陈怀民在监控我"
  所需: [未接来电4秒, 陈怀民敲门时间与来电时间的关联]
  激活: truthLayer += 10, 排除陈怀民是"普通房东"

知识: "门外警察是假的"
  所需: [真警察问话方式, 假警察问话方式, 回拨110没有出警记录] 中任意2项
  激活: truthLayer += 15, 解锁调查方向"谁在调动假警察"

知识: "林越在追查李汶涛失踪"
  所需: [林越的遗言, 403桌上的烟盒, 林越拒绝报警的理由]
  互斥: "林越是帮凶"
  激活: truthLayer += 15, 排除林越是帮凶, 解锁同盟

知识: "1103 = 赵鸿远"
  所需: [U盘内容, U盘密码, 403笔记本中的成员代号]
  激活: truthLayer += 25, 解锁真相 L4

知识: "组织有公安内线"
  所需: [U盘账本中有警号, 赵鸿远提前知道报警, 真警察被拖延]
  激活: truthLayer += 15, externalReach 计算方式改变（需要绕过内线传证据）
```

### 知识激活的叙事反馈

不是"任务提示"，是角色内心认知的自然反映：

| 知识激活 | 叙事反馈 |
|---------|---------|
| "包裹是寄错到 503 的" | 这不是我的快递。403——这栋楼里有另一个人。 |
| "陈怀民在监控我" | 他知道我在家。23:01 那通电话不是打错了。他在确认。 |
| "门外警察是假的" | 没有警车声。他问的问题太具体了——像在套话，不像在核验。 |
| "林越在追查李汶涛失踪" | 他不是在盯我。他在盯这栋楼。他说的"那个人"——是寄包裹的人。 |
| "1103 = 赵鸿远" | 1103。账本里每一行都有这个编号。陈怀民的名片背面，也是它。 |
| "组织有公安内线" | 报警被压下来了。他们不是第一次这么做。 |

玩家读完后的自然反应是"顺着这个方向继续查"——而不是被系统命令式地推着走。

## 十一、可变凶手：多线并发机制

### 核心原则

**不是"陈怀民压力值决定一切，其他人是他的分支选项"。** 每个可能的凶手独立评估当前世界状态，各自有触发阈值。谁的条件先满足，谁就动手。

### 三条并行死亡线

```
                        玩家行动
                           ↓
        ┌──────────────────┼──────────────────┐
        ↓                  ↓                  ↓
   陈怀民线            假警察线            赵鸿远线
   (默认最近)         (组织资源)          (远程裁决)
        ↓                  ↓                  ↓
   他知道了什么？      被调用了没有？      他知道了什么？
   他有多害怕？        调用理由成立吗？    值得亲自介入吗？
   还能自己搞定吗？    上次调用间隔？      陈怀民还可用吗？
        ↓                  ↓                  ↓
   阈值触发 → 灭口    阈值触发 → 执法    阈值触发 → 清理
```

林越不是凶手线——他是嫁祸路径的受害者。嫁祸在陈怀民线上触发：陈怀民动手 + 故意留线索指向林越。

### 陈怀民线

```
陈怀民知道的:
  - 包裹被拆了？(是/否)
  - 玩家拍照了？(是/否)
  - 玩家报警了？(是/否)
  - 林越和玩家接触了？(是/否)

陈怀民的决定:
  if 赵鸿远还没注意到 AND 自己能搞定:
      → 灭口（亲自来）
  if 赵鸿远还没注意到 AND 自己搞不定 AND 假警察可用:
      → 叫假警察（执法路径）
  if 赵鸿远已经注意到了:
      → 被动等待，赵鸿远决定
  if 林越知道太多了 AND 能让林越上楼:
      → 嫁祸（动手 + 留林越的痕迹）
```

### 假警察线

```
假警察不一定要等陈怀民调用——赵鸿远可以直接调:

  触发条件（任一满足）:
  - 陈怀民调用了他们
  - 赵鸿远直接调用了他们
  - 真警察到了附近（假警察需要"抢先"）

  假警察的行动:
  - 冒充警察查案——"503 有人报警说有可疑包裹"
  - 如果玩家质疑 → 转威胁
  - 如果玩家配合 → 拿走包裹 → 评估是否需要灭口
```

### 赵鸿远线

```
赵鸿远知道的（非实时——有信息延迟）:
  - 来源: 陈怀民汇报 + 公安内线消息
  - 关键: 陈怀民撒谎时，赵鸿远知道的版本是错的

赵鸿远的判断:
  if 真警察到了青荷公寓 AND 内线告诉他 503 报警了:
      → 事情闹大了。陈怀民靠不住。派人清理。
  if 陈怀民连续 N 个电话不接:
      → 陈怀民出事了。直接行动。
  if 外部有人开始查李汶涛:
      → 组织在暴露。收线。
```

### 信息延迟是关键

陈怀民线实时——他在楼里。赵鸿远线延迟——他靠陈怀民汇报，而陈怀民在撒谎。玩家可以利用这个时间窗口：在赵鸿远知道真相之前，把证据传出去。这也是为什么"通知林越"会改变局势——不是直接触发赵鸿远，而是信息从陈怀民控制的圈子漏出去了，最终延迟到达赵鸿远。

## 十二、跨循环持久化

### 哪些东西跨循环保留？

| 数据类型 | 是否保留 | 理由 |
|---------|---------|------|
| 已发现的物理证据 | ✅ 保留 | 玩家已经知道它在哪——不需要重新翻一遍抽屉。未发现的仍然隐藏。 |
| 已激活的知识 | ✅ 完全保留 | 玩家"想通了的事"不会忘 |
| 循环记忆（loopMemory） | ✅ 保留 | 已有的机制，继续用 |
| NPC 关系状态 | ⚠️ 部分保留 | 林越的信任度保留，但每轮需重新联系 |
| 玩家受伤状态 | ❌ 重置 | 身体回到 23:00 的状态 |

### 证据保留的语义

不是"东西凭空出现在玩家手里"——而是**玩家已经知道了位置，不需要重复发现动作**：

- 第一轮发现"U盘在包裹夹层里" → 之后每一轮 U盘位置已知，`inspect包裹` 跳过，U盘可直接使用
- 第一轮发现"403 地砖下有笔记本" → 之后每一轮进入 403 后笔记本自动可见
- 第一轮发现"雨棚上有烟蒂" → 之后每一轮看向窗外时烟蒂直接在描述里
- 未发现过的 → 仍然需要探索

### 知识继承的叙事表达

每轮开场叙事根据已有知识变化，不再是固定的"雨声贴着窗玻璃……"：

```
第一轮（什么都不知道）:
  "沈知夏在出租屋地板上醒来，手机屏幕停在 23:00。
   桌边有一个被拆开一半的纸箱。"

第三轮（知道了"包裹不是我的" + "陈怀民在监控我"）:
  "又是 23:00。她看了一眼桌上的纸箱——她很清楚里面是什么。
   还有 47 分钟。她拿起手机。23:01，那个空号会响四秒。"

第五轮以上（知道了"门外警察是假的" + "林越在追查李汶涛"）:
  "她睁开眼。23:00。
   前几轮的记忆压在胸口——假警察的措辞、林越说的'那个人'、
   403 门缝里透出来的霉味。她比上次多知道了一些事。
   这次，她知道该问谁。"
```

### 数据模型

```typescript
interface GameState {
  // ... 现有字段 ...

  /** 跨循环已激活的知识 —— 循环重置不丢失 */
  activatedKnowledge: KnowledgeRecord[];

  /** 跨循环已发现的线索 ID 集合 —— 循环重置不丢失 */
  discoveredClueIds: string[];

  /** 当前循环新激活的知识（本轮新增） */
  currentRunKnowledge: KnowledgeRecord[];
}

interface KnowledgeRecord {
  id: string;                    // e.g. "package_not_for_me"
  label: string;                 // "包裹是寄错到 503 的"
  activatedAt: { run: number; minute: number };
  sourceClueIds: string[];       // 支撑这条知识的线索 ID
  truthLayerContribution: number;
}
```

循环重置时：
- `activatedKnowledge` → 保持不变
- `discoveredClueIds` → 保持不变，已发现的线索自动标记为已知
- `currentRunKnowledge` → 清空
- `clues` → 已发现的保留标记，未发现的清空
- 新轮开场叙事根据 `activatedKnowledge` 变化

## 十三、断案系统

### 叙事式断案

不是问答，不是空白文本框。系统把已知的线索碎片摊在玩家面前，递一个话头，让玩家接着说：

```
系统展示:

  你靠在门边，把这几轮的记忆在脑子里过了一遍。

  包裹面单上残破的"青荷 5-0"。
  403 收据上那个陌生的名字。
  陈怀民名片背面的数字。
  门外的人——问话方式不像警察。

  这些碎片拼在一起——
```

系统展示的是**线索**，不是**命题**。不替玩家总结"你知道包裹不是寄给你的"——只列出原始线索，让玩家自己说出它们意味着什么。

### 校验 + 灵光一现

玩家回答后，系统拆成命题对照知识库校验。如果连续错误，触发灵光一现：

| 连续错误 | 灵光强度 | 效果 |
|---------|---------|------|
| 2 次 | 微光 | 角色注意到一个之前忽略的细节——不明确指向 |
| 4 次 | 闪烁 | 角色想起一条具体线索——暗示调查方向 |
| 6 次 | 骤亮 | 角色连接了两个线索——接近直接说明 |

灵光示例（缺失知识"林越在追查李汶涛失踪"）：

**微光:** 她脑子里忽然闪过一个画面——林越那天在走廊，不是在看她的门。他在看楼下。

**闪烁:** 等一下。林越提到过一个人。"之前住 403 的那个"。他说这话的时候把声音压得很低。

**骤亮:** 403。李汶涛。林越不是在盯她——他在找这个人。李汶涛失踪之前，最后一个跟他说话的人，是林越。

### 灵光设计原则

- 不指令——不说"去 403 看看"
- 角色视角——沈知夏的内心活动，不是上帝视角
- 指向线索而非结论——提示"有个东西你没注意"，不是"真相是什么"
- 逐级递进——越来越具体，但始终是角色自己能想到的
- 每次只给一个方向——指向级联影响最大的那条缺失知识
